# BUMP Archive

这里是《大邮数学集》（*Bigdu[^1] University Mathematics Problemset*）的归档仓库。

本仓库不包含《大邮数学集》的源码；实际上，《大邮数学集》目前并不开放源码和社区 PR。如果您想参与《大邮数学集》的建设，请参见 [Contribution](#Contribution)。

## Community

- [fa\_555 Pub](https://pub.fa-555.com/) 是我近期搭建的内容发布站点。这里会发布《大邮数学集》的最新版和最新快照版、它们的元数据，以及**临时勘误表**和**勘误问卷**的链接，以及其他可能有用的材料。
  - fa\_555 Pub 有 RSS 服务，欢迎订阅以即时获取更新。
  - 快照版《大邮数学集》会包含没有答案的套题。
  - 临时勘误表包含已经修改但尚未正式发布的勘误；在提交勘误问卷前，请确保你使用的《大邮数学集》是当前的最新版本，否则将被我们的工作流自动标记为无效问卷。
- QQ 读者群[大邮数学集 | 读者交流](https://qm.qq.com/q/nrS4NoT8VG)（群号 532334429）。
  - 目前的加群问题为“材料启动日期 YYMMDD”，答案为 `250111`。
  - 可在群聊内提供建议，或是单纯来吹吹水。若想提供帮助，可在此寻找群管理员。
- GitHub 归档仓库（本仓库）。
  - 通过 Issues 区或其他方式联系#ruby[主编][仓库所有者]。

## Contribution

若想提供题目、校对、维护、排版、宣传或法律支持，请参照 [Community](#community) 一节联系我们。衷心感谢你的**无偿**贡献，你将有权把自己加入贡献者列表中。

## AI 声明

《大邮数学集》的排版样式和功能性代码没有生成性 AI 的参与。AI 目前被应用在题目识别、答案编写、流程自动化等工作中，与人类发挥了同等重要的作用。

## Roadmap

本书将持续收集反馈、套题，并发布新版本；也乐于接受更多数学课程的资料。

相信大家都能看出编辑工作量的巨大，因此我本人很遗憾地无力提供答案的详细解析。

由于一些原因，本书不会收录中外合作办学专业的英语或双语试题。

本书不计划公开内容的源码。

[^1]: 我知道大都是 Dadu 或者 the Great Capital，叫作 Bigdu 只是想凑出一个 B 来。
